# @slideglance/measure — Reference

## Package shape

```
packages/measure/
├── package.json
├── README.md
├── LICENSE
├── docs/en/{index,reference,guides}.md
└── dist/                  # produced by wasm-pack
    ├── web/
    ├── bundler/
    └── node/
```

The package contains no hand-written TypeScript. The public surface
is generated by `wasm-pack` from
[`crates/slideglance-measure-wasm`](../../../../crates/slideglance-measure-wasm/docs/en/reference.md).

export default function init(input?: InitInput): Promise<InitOutput>;

|---|---|---|
| `init` | function | Module instantiation |

### `class TextMeasurer`

| Method | Signature (TS) | Purpose |
|---|---|---|
| Constructor | `new TextMeasurer(buffers: Uint8Array[])` | Parse each font file once |
| `measureWidth` | `(text, family, sizePt, bold, ...) => number` | Pixel advance |

For the exact method list (which includes ascent / descent helpers),
see the generated `.d.ts` files under `dist/*/`.

## Parity with `@slideglance/core`

`TextMeasurer` uses the same resolver chain
(`Mapped(CjkFallback(Buffer))`) as the renderer. A host that drives
both packages with the same fonts gets pixel-identical advances on
either side — the primary reason this package exists.

## Build pipeline

```
crates/slideglance-measure-wasm   →   wasm-pack   →   packages/measure/dist/{web,bundler,node}
```

Same shape as `@slideglance/core`; the only difference is the source
crate. Manifest workaround for `wasm-pack` is documented on the
underlying crate's reference page.
