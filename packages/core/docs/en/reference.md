# @slideglance/core — Reference

## Package shape

```
packages/core/
├── package.json
├── README.md
├── LICENSE
├── docs/en/{index,reference,guides}.md
└── dist/                  # produced by wasm-pack
    ├── web/
    ├── bundler/
    └── node/
```

The package contains no hand-written TypeScript. Its public surface
is generated by `wasm-pack` from
[`crates/slideglance-wasm`](../../../../crates/slideglance-wasm/docs/en/reference.md).

## Default export

```ts
export default function init(input?: InitInput): Promise<InitOutput>;
```

Loads and instantiates the WASM module. Must be called once before
any other export. After `await init()`, the named exports below are
ready.

## Named exports

| Export | Kind | Purpose |
|---|---|---|
| `init` | function | Module instantiation |
| `version` | function | Returns the crate version string |
| `emu_to_pixels(emu)` | function | Convenience EMU → px conversion |
| `parse_pptx_data(bytes)` | function | Returns a serialized `Presentation` |
| `convert_pptx_to_svg(bytes, opts)` | function | One SVG per slide |
| `convert_pptx_to_png(bytes, opts)` | function | One PNG per slide |
| `svg_to_png_wasm(svg, opts)` | function | SVG → PNG via the deterministic rasterizer |
| `PptxDocument` | class | Stateful incremental rendering |

For exact signatures, see the `.d.ts` files produced under `dist/*/`.

## JS-side callbacks (optional)

The WASM module imports two globals the host **may** install on
`globalThis`:

| Global | Purpose |
|---|---|
| `__slideglanceMeasureText(text, family, familyEa, chain, sizePt, bold) => number` | Pixel advance |
| `__slideglanceMeasureLineMetrics(fontDecl) => { ascent, descent, lineGap }` | Vertical metrics |

When absent, the Rust side falls back to its heuristic measurer and
logs a `console.warn`. The
[`viewer`](../../../viewer/docs/en/index.md) installs both via an
`OffscreenCanvas` worker; standalone hosts can do the same.

## Determinism

Identical input bytes + identical options + identical font buffers →
bit-identical output, across Node and every browser target. See
the [`slideglance-png` determinism note](../../../../crates/slideglance-png/docs/en/reference.md#determinism-contract).

## Build pipeline

```
crates/slideglance-wasm   →   wasm-pack   →   packages/core/dist/{web,bundler,node}
```

`pnpm --filter @slideglance/core build` runs `wasm-pack` three times
(once per target) and copies the outputs into the matching `dist/`
subdirectory. The `package.json` `"exports"` field maps each entry
point.
