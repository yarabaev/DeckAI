# @slideglance/builder — Reference

## Package shape

```
packages/builder/
├── src/
│   ├── index.ts             # public exports
│   ├── buildPptx.ts         # buildPptx entry point
│   ├── parseXml/            # XML → BuilderDocument
│   ├── preprocess/          # equalize, etc.
│   ├── calcYogaLayout/      # Yoga (Flexbox) integration
│   ├── codegen/             # PPTX writer
│   ├── autoFit/             # text auto-fit
│   ├── icons/               # icon registry
│   ├── diagnostics.ts       # DiagnosticsError, Diagnostic
│   ├── defaultTextStyle.ts
│   ├── buildContext.ts
│   └── …
├── builder.xsd              # XSD schema (.sgx)
├── builder.schema.json      # JSON Schema mirror
├── reference.md             # registry-level field reference (generated)
└── docs/en/{index,reference,guides}.md
```

> `packages/builder/reference.md` is the **field-by-field schema
> reference** generated from the registry. The doc you are reading
> is the *package-level* reference; for individual element
> attributes consult `reference.md`.

## Top-level exports

| Export | Kind | Purpose |
|---|---|---|
| `buildPptx` | function | XML string → `.pptx` byte buffer |
| `BuildPptxResult`, `BuildPptxOptions` | types | `buildPptx` arg / return shapes |
| `TextMeasurementMode`, `ImageSrcGuardOptions`, `MasterPptxLimits` | types | Tunables on `buildPptx` |
| `DiagnosticsError`, `Diagnostic`, `DiagnosticCode` | types | Error reporting |
| `parseBuilderDocument`, `ParseXmlError` | function + type | Parse XML to typed `BuilderDocument` |
| `ParseResult`, `ParsedBuilderDocument`, `ParseBuilderDocumentOptions`, `ImportResolver`, `BuilderSourceMap`, `BuilderSourcePos` | types | Parse output shapes |
| `equalizeAll`, `collectStylesMap`, `StyleEntry` | function + type | Style equalisation pass |
| Many `*Node` types and style atoms | types | Document tree types |

The full public type list (~50 named exports) is in
[`src/index.ts`](../../src/index.ts). The
field-level schema for each node lives in the registry, mirrored in
`builder.xsd` and `builder.schema.json`.

## Node types (selected)

`BuilderNode` is the discriminated union all elements ultimately
narrow into. Subsets include:

- **Text**: `TextNode`, `UlNode`, `OlNode`, `LiNode`
- **Image / icon / SVG**: `ImageNode`, `IconNode`, `SvgNode`
- **Containers**: `VStackNode`, `HStackNode`, `LayerNode`
- **Shapes**: `ShapeNode`, `LineNode`
- **Tabular / charting**: `TableNode`, `ChartNode`
- **Positioned**: `PositionedNode`, `PositionedLayerChild`

Each node carries the style atoms relevant to it (`Length`,
`Padding`, `Border*`, `LineArrow`, etc.).

## Pipeline

```
.sgx XML
   ↓ parseBuilderDocument
ParsedBuilderDocument
   ↓ equalizeAll / preprocess
   ↓ calcYogaLayout (Flexbox)
   ↓ codegen
.pptx ByteBuffer
```

## Determinism

Identical XML + identical fonts + identical options produces
bit-identical PPTX bytes. Text widths come from
[`@slideglance/measure`](../../../measure/docs/en/index.md) (or a
configurable measurer, see `TextMeasurementMode`).

## Schemas

- `builder.xsd` — XSD for editor / IDE integration
- `builder.schema.json` — JSON Schema (autogenerated from the
  TypeScript types) — used by the `.sgx` language server in
  [`vscode-extension`](../../../../apps/vscode-extension/docs/en/index.md).
